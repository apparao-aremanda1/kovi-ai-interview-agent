# kovi-ai-interview-agent
Kovi by techeval.ai is an autonomous AI technical interviewer tailored by seniority (Junior to Architect). Runs initial screens, deep dives, &amp; system design with custom pass scores, tech stacks, must-ask questions, &amp; smart proctoring. Auto-evaluates engineering talent 24/7 to scale hiring to 1,000+ screens/day with zero human fatigue.
## Key Capabilities & Configurable Parameters

| Feature | Options & Customization | Purpose |
|---|---|---|
| **JD & Resume Parsing** | Automated tech stack & project extraction | Constructs tailored, role-specific evaluation tracks based on candidate history |
| **Kovi Voice Agent** | Real-time conversational dialogue | Enables adaptive follow-ups and deep technical probing in a natural format |
| **Interview Types** | Initial Screening, Technical Deep Dive, Behavioral & Culture Fit, System Design, Full Stack Evaluation | Matches the exact stage of your recruitment pipeline |
| **Seniority Levels** | Junior / Foundation, Mid-Level / Execution, Senior / Architecture | Adapts question complexity and evaluation rubric to candidate YOE |
| **Tailored Tech Stacks** | Fully editable (e.g., Python, LangChain, PostgreSQL, Next.js) | Focuses the dialogue strictly on your production stack |
| **Must-Ask Questions** | Editable custom prompt injections | Ensures critical compliance or role-specific questions are answered |
| **Evaluation Controls** | Configurable Duration (mins) & Pass Score threshold | Sets objective quantitative benchmarks for candidate filtering |
| **Deadlines & Expiration** | Configurable hour deadlines (e.g., 48 Hours) | Enforces strict link-expiration rules to maintain pipeline velocity |
| **Proctoring Engine** | Live webcam monitoring, gaze tracking, multi-person detection, tab-switch logging | Prevents proxy attendance and ensures interview integrity |
| **AI Copilot Detection** | Cadence analysis & real-time technical curveballs | Actively exposes candidates relying on ChatGPT or generative AI assistants |
| **Session Recovery** | Auto-saves conversation states | Allows candidates to seamlessly reconnect and resume if their network drops |
| **Instant Scorecards** | Objective 1-10 scores, proctoring flags, key strengths, full transcripts | Delivers immediate, actionable hiring data directly to HR |
